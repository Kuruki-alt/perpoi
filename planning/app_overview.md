# アプリ概要：コスパ計算ツール

## コンセプト

買い物中にその場でサッと使える、電卓的なコスパ計算Webアプリ。  
「割引後の価格はいくら？」「ポイントを加味すると実質何%お得？」を即座に把握できる。

---

## ターゲットユーザー

- 節約・コスパを意識している人全般
- スーパーでの食料品購入・ネットショッピングどちらでも使う人

---

## 解決する悩み

1. セールで「○○%OFF」と表示されているが、元値が分からず本当にお得か判断できない
2. ポイント還元率を加味した実質価格が瞬時に計算できない

---

## 機能仕様

### 機能1：割引計算

| 項目 | 内容 |
|------|------|
| 入力 | セール価格（円）、割引率（%OFF） |
| 出力 | 元値（円）、割引額（円） |

### 機能2：ポイント還元計算

| 項目 | 内容 |
|------|------|
| 入力 | 元値（円）、ポイント還元率（%） |
| 出力 | 獲得ポイント数（pt）、実質価格（円）、実質割引率（%） |

### 機能3：割引 ＋ ポイント還元の組み合わせ計算

| 項目 | 内容 |
|------|------|
| 入力 | セール価格（円）、割引率（%OFF）、ポイント還元率（%） |
| 出力 | 元値（円）、割引額（円）、獲得ポイント数（pt）、実質価格（円）、実質割引率（%） |

---

## UI・操作フロー

- **対応デバイス：** スマホメイン（モバイルファースト設計）
- **画面構成：** 1画面にすべてまとめる（スクロール型）
- **結果表示：** 入力と同時にリアルタイムで結果を更新する（ボタン不要）

---

| 項目 | 内容 |
|------|------|
| フロントエンド | HTML / CSS / JavaScript |
| バックエンド | なし（静的ファイルのみで完結） |

## 補足・制約

- サーバーサイド処理は不要。すべてブラウザ上で完結する。
- 外部ライブラリ・フレームワークは使用しない。
- ファイル構成はシンプルに `index.html` 1ファイルを基本とする。
